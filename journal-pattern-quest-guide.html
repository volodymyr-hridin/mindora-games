How to spot the missing shape in Pattern Quest

When a grid contains triangles, circles and stars, the trick is not to memorize every symbol. Look for the rule that determines where each shape belongs. Mindora Pattern Quest uses five short puzzles in its daily challenge, and each one has a missing tile to identify.

Start with the real game

Each puzzle shows a three-row, five-column pattern with one question-mark tile. Choose the symbol that fits the underlying rule. Your daily result is scored out of 500 points, with 100 points available per correct answer.

Rule 1: alternating columns

Sometimes the pattern simply alternates between two symbols as you read across a row. Consider this example:

▲ ● ▲ ● ▲
▲ ● ? ● ▲
▲ ● ▲ ● ▲

The missing symbol is ▲. Each column repeats the same shape across the three rows. Start by checking the tiles immediately to the left and right of the question mark.

Rule 2: a shifting three-shape cycle

A different pattern rotates three symbols. The next row starts one step further along the sequence:

▲ ● ◆ ▲ ●
● ◆ ▲ ● ◆
◆ ▲ ? ◆ ▲

The missing symbol is ●. Reading left to right, the repeating cycle is ▲, ●, ◆. Reading down, each row begins at the next position in that cycle.

Rule 3: the whole row is the clue

Not every puzzle alternates within a row. Sometimes each row contains only one repeated shape, and the rows alternate:

★ ★ ★ ★ ★
● ● ● ● ●
★ ★ ? ★ ★

The answer is ★. Looking only at the column above the question mark might be misleading; look across the entire row first.

A quick three-step solving routine

  1. Scan horizontally: does the row alternate every tile, cycle every three tiles, or repeat one shape?
  2. Check vertically: do the rows match, shift, or alternate as a group?
  3. Verify the answer: mentally replace the question mark and check whether the complete grid follows the same rule.

Daily challenge or practice round?

Pattern Quest offers a daily set of five puzzles. Once you finish, you can start a new practice round with a fresh arrangement. Daily progress is saved in your browser, so you can return to your result later. Optional timed challenges add urgency; for learning the rules, begin without a timer.

Common mistakes

Guessing from neighboring shapes alone: a local match can be misleading if the full grid follows a three-shape cycle. Ignoring the row above: some rules depend on the starting symbol of each row. Rushing: confirm the pattern across at least two complete rows before selecting an answer.

Try the method on a real puzzle

On your next round, name the rule before tapping an option: “alternating columns,” “shifting cycle,” or “repeated row.” This habit helps you solve deliberately rather than guessing.
