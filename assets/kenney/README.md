# Hole World 3D - third-party art assets

These assets are Kenney 3D models from the following Creative Commons Zero 1.0 (CC0-1.0) packs:
- City Kit (Suburban): https://kenney.nl/assets/city-kit-suburban
- City Kit (Commercial): https://kenney.nl/assets/city-kit-commercial
- Car Kit: https://kenney.nl/assets/car-kit
- Nature Kit: https://kenney.nl/assets/nature-kit
- Food Kit: https://kenney.nl/assets/food-kit

Original author: Kenney (https://kenney.nl/).
Downloaded from public CC0 3D model catalog maintained at https://github.com/Hidencod/tge-assets (model catalog as of 2026-10-28).

Each *.b64 text file is the original self-contained *.glb binary re-encoded as base64 to allow safe text-only publication through the GitHub Contents API. It is decoded to an ArrayBuffer in the browser and parsed by Three.js GLTFLoader. Models are cached and cloned for repeat use; original geometric content and authored materials are retained.

Included models:
- house-a / house-c / house-e: City Kit (Suburban), building-type-a/c/e
- shop-a / shop-c: City Kit (Commercial), building-a/c
- car-sedan / car-taxi / car-van: Car Kit, sedan/taxi/van
- tree-detailed / tree-oak: Nature Kit, tree-detailed/tree-oak
- food-apple / food-donut / food-cupcake / food-burger: Food Kit, apple/donut-sprinkles/cupcake/burger
