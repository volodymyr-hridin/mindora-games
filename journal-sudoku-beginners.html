Sudoku for beginners: find your first certain number

Sudoku is not a guessing game. Every empty cell has a set of possible digits, and the goal is to reduce those possibilities until one answer is certain.

The rules in 30 seconds

Fill a 9×9 grid so that each row, each column and each 3×3 box contains every digit from 1 through 9 exactly once. The given numbers cannot be changed.

Open a Sudoku puzzle

1. Scan the nearly complete rows

Suppose a row already contains 1, 2, 3, 4, 5, 6, 7 and 9. Its missing number must be 8. Before placing it, confirm that the column and the 3×3 box also permit 8. This is a naked single: the cell has only one possible candidate.

2. Look for a digit with only one home

A 3×3 box might have several empty cells, but perhaps only one of those cells can contain 5 because the others share a row or column with another 5. Then place 5 there. This is a hidden single: the digit has only one possible location in that box.

3. Use pencil notes, not guesses

For a harder cell, write down the digits absent from its row, column and box. The intersection of those three sets gives its candidates. Recheck the notes after every confirmed placement; removing a candidate may reveal the next single.

A quick practice exercise

In a row containing 1, 3, 4, 5, 6, 7, 8, 9, what number is missing? It is 2. In a real Sudoku, you would also check that the relevant column and box allow 2.

Three mistakes to avoid

  1. Placing a number just because it looks likely. Sudoku needs proof.
  2. Checking the row but forgetting the column or 3×3 box.
  3. Keeping outdated pencil notes after filling nearby cells.

Put the techniques to work

Start on Easy difficulty, scan for singles, then switch to Medium once you can solve without guessing.
