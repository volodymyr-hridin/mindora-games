Privacy Notice

Last updated: October 21, 2026.

Mindora Games is currently an early-access website offering free browser games. This notice describes the website as currently implemented; it must be reviewed before advertising, analytics or account features are enabled.

Local game progress

The games use your browser's localStorage to remember scores, streaks and daily puzzle completion. These values remain in your browser and can be removed by clearing this site's browser data. They are not used for cross-site advertising.

Hosting

The website is currently served by GitHub Pages. As with other hosting services, GitHub may process technical connection data such as IP addresses according to its own policies. See GitHub's privacy statement.

Advertising and analytics

We have not added Google AdSense or Google Analytics tracking to the current test website. If these services are introduced, this notice and the site's consent controls will be updated first.

Contact and controller details

Operator identity, contact address and any legally required controller information will be published before the commercial launch. This early-access notice is not a substitute for a complete legal privacy policy.
